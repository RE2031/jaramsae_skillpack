# 어린이집 인스타그램 최초 설정 질문지

안녕하세요, 원장님! 어린이집만의 분위기와 교육 철학이 담긴 인스타그램 콘텐츠를 제작하기 위해 몇 가지 여쭤볼게요. 편하게 답변해 주세요. 한 번 설정하면 이후에는 오늘의 활동 내용이나 사진만 전달하셔도 됩니다(기관 프로필을 저장하고 불러올 수 있는 환경 기준).

## 어린이집 정보

1. **어린이집 이름은 무엇인가요?**
   - 인스타그램 표지에 표시할 이름을 정확히 적어 주세요.
   - 예: 햇살숲
2. **어떤 연령대의 아이들이 다니고 있나요?**
   - 예: 만 1~5세
3. **우리 어린이집의 교육 철학은 무엇인가요?**
   - 예: 아이들이 놀이를 통해 스스로 배우고 성장하는 교육
4. **우리 어린이집만의 강점은 무엇인가요?**
   - 예: 자연 친화적인 환경과 다양한 놀이 활동

## 인스타그램 운영 목적

5. **인스타그램을 어떤 목적으로 운영하고 싶으신가요?** (복수 선택 가능, 직접 입력 가능)
   - 학부모에게 아이들의 일상과 활동 전달
   - 어린이집의 교육 철학 소개
   - 신규 원아 모집
   - 어린이집의 전문성과 신뢰감 형성
   - 기타: 자유롭게 작성

## 원하는 분위기

6. **어떤 분위기와 말투의 인스타그램을 원하시나요?**
   - 예: 따뜻하면서도 전문적이고 학부모가 보기 편한 분위기. 사진과 정보를 적절히 활용하고 교사가 직접 아이들의 하루를 기록하듯 자연스러운 문구.
   - 기존에 좋아하는 피드나 브랜드 색상이 있다면 선택적으로 알려 주세요. 디자인 전문 용어는 필요하지 않습니다.
