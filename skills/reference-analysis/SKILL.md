# reference-analysis

사용자가 제공한 캡처에서 여백, 글자 크기 비율, 색 대비, 이미지 비중, 정렬, 제목 위치, 피드 리듬을 관찰한다. 실제로 열람하지 못한 계정은 분석했다고 주장하지 않는다. 로고, 캐릭터, 사진, 고유 카피, 완성 디자인을 복제하지 않는다. styles/*.json 중 가까운 프리셋을 선택하고 기관 자체 색상을 적용한다.

## 풀블리드 고밀도 사진형 레퍼런스 분석
사용자가 제공한 레퍼런스에서 다음의 일반적 디자인 문법을 추출할 수 있다.
- 각 게시물은 세로형 사진이 화면을 끝까지 채우며 외곽 카드 여백이 거의 없다.
- 사진 위에 얇은 어두운 오버레이가 있고 하단으로 갈수록 강해지는 검정 그라데이션이 제목을 받친다.
- 상단 중앙에 작은 브랜드 표식이 반복되어 피드 전체의 일관성을 만든다.
- 하단에는 작은 도입 문구와 매우 큰 흰색 굵은 제목이 계층적으로 놓인다.
- 표지에는 제목 아래 보조 문구를 넣지 않고 하단의 작은 출처만 둔다.
- 사진은 게시물마다 바뀌지만 텍스트 위치와 브랜드 표식은 일관되게 유지한다.
이 원리를 기관의 콘텐츠와 브랜드에 맞게 재해석한다. 레퍼런스 계정의 로고, 인물 사진, 정확한 문구, 독점적 그래픽 요소는 가져오지 않는다.

## TIO 우선 매거진 시안 — 최신 우선 지침
`references/magazine-editions.md`를 먼저 읽는다. TIO(@tio_korea)는 표지 최우선 레퍼런스이며 기존 승인 Signature Cover는 A에 그대로 보존한다. MMM, Eyesmag, 생매거진, Our Expresso는 시안별 보조 레퍼런스다. B/C/D도 풀블리드, 상단 중앙 기관명, 하단 얇은 도입 문구, 정확히 두 줄 굵은 흰색 제목, 우측 하단 출처, 표지 본문 없음이라는 TIO 기반 구조를 유지하면서 타이포/명암/여백을 변주한다. 네 시안에서 사진·활동 사실·카피·브랜드는 동일하게 유지하고 실제 CSS 배치·서체·사진 영역을 다르게 한다. 본문은 아직 사용자 최종 승인 전인 후보 디자인이며 기존 A를 유지한다. 네 시안은 각 4장 한 줄, 총 16장 편집기로 제공한다. 단일 표지 요청에는 A를 기본으로 한다. 원본 권리 확인 및 실제 파이프라인 검수는 기존 규칙을 유지한다.
