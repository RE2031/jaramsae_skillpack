# post-composition

기본 캔버스는 1080×1350px(4:5)다. 기본 스타일은 `bold-photo-editorial`이다. 각 슬라이드는 승인된 사진이 캔버스 전체를 채우고, 텍스트는 하단의 어두운 그라데이션 위에 배치한다.

## 기본 구성
- 이미지: 100% 캔버스, 외곽 여백 없음, 카드 테두리 없음.
- 브랜드: 상단 중앙에 기관명 또는 승인된 로고를 작게 배치.
- 도입 문구: 하단 제목 바로 위에 작은 크기와 가벼운 굵기로 배치.
- 제목: 흰색, 굵은 산세리프, 보통 2~3줄. 가장 큰 시각 요소.
- 본문: 제목 아래 1~2줄. 제목을 반복하지 않고 부모에게 필요한 맥락을 보완.
- 출처/슬라이드 정보: 맨 아래 작은 크기로 배치.
- 그라데이션: 하단 40~50%를 충분히 어둡게 하되 사진의 맥락이 완전히 사라지지 않게 한다.

## 사진과 글자 배치
사진의 주요 얼굴과 활동 디테일은 상단 또는 중앙에 둔다. 텍스트가 놓이는 하단에 중요한 손동작, 작품, 표정이 가려지지 않도록 이미지 크롭과 image_position을 조정한다. 제목은 2~3줄, 본문은 최대 2줄을 권장한다. 기본 안전 여백은 좌우 64px 이상, 상단 40px 이상, 하단 48px 이상이다.

## 캐러셀 구성
1. 표지: 활동 전체가 한눈에 보이는 사진 + 작은 도입 문구 + 강한 제목.
2. 활동 과정: 손, 재료, 상호작용 등 다른 거리/각도의 사진 + 짧은 설명.
3. 의미 전달: 실제 관찰에 근거한 활동의 의미 + 관련 사진.
4. 마무리: 완성 작품이나 자연스러운 마무리 사진 + 짧은 문구.

각 슬라이드의 사진은 달라야 한다. 같은 사진을 단순 크롭만 바꿔 반복하지 않는다. 그래픽 문법은 통일하되 장면, 인물 위치, 촬영 거리를 다양화한다. 제목과 본문이 사진을 과도하게 덮지 않게 한다.

## 다른 스타일
정보가 많거나 학부모 안내가 중심인 요청에는 `editorial-hybrid` 또는 `minimal-information`을 선택한다. 기존 레이아웃과 JSON 스키마에서 지원하는 이름만 사용한다.
