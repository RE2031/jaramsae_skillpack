# post-composition

기본 캔버스는 1080×1350px(4:5)다. 기본 스타일은 editorial-hybrid이며 사진과 텍스트의 시각적 비중을 대략 균형 있게 둔다. 이는 모든 슬라이드에 사진과 문장을 절반씩 넣으라는 뜻이 아니다. 각 슬라이드의 메시지와 이미지 구도에 맞춰 조정한다.

## 레이아웃 선택
- hero-left-copy / hero-right-copy: 활동 대표 사진과 큰 제목을 결합한 표지.
- split-photo / split-editorial: 사진과 제목·설명을 분리해 사진과 정보가 모두 읽히게 구성.
- detail-photo / photo-caption: 손, 재료, 과정 등 구체적 활동 디테일과 짧은 설명.
- text-interlude / quiet-cover: 핵심 의미를 큰 제목과 여백으로 전달하는 전환 슬라이드. 텍스트 슬라이드가 연속되지 않도록 한다.
- fullbleed-photo: 강한 대표 장면이 필요할 때 제한적으로 사용한다. 사진만 있는 장면이 연속되지 않도록 정보 슬라이드와 조합한다.
- minimal-announcement: 모집·일정·안내 등 정확한 정보가 중심일 때 사용한다.

## 기본 4장 캐러셀
1. 표지: 활동 전체가 보이는 대표 장면 + 큰 제목 + 한 줄 설명.
2. 활동 디테일: 손/재료/과정의 클로즈업 + 실제 활동 설명.
3. 활동의 의미: 학부모가 이해하기 쉬운 핵심 정보 + 보조 사진 또는 타이포그래피.
4. 마무리: 완성 작품/자연스러운 마무리 장면 + 짧은 정리 문구.

순서는 콘텐츠 목적과 사용 가능한 사진에 따라 바꿀 수 있다. 동일한 레이아웃, 동일한 사진, 동일한 카메라 구도를 반복하지 않는다. 사진이 메시지 전달에 도움이 되지 않으면 억지로 넣지 않는다. 한 장에는 하나의 핵심 메시지만 둔다. 제목은 크게, 본문은 모바일에서 읽기 쉬운 길이로 작성한다. 사진과 텍스트가 서로 경쟁하지 않도록 충분한 여백과 대비를 확보한다.

기존 레이아웃을 우선 활용한다. JSON 스키마와 CSS에서 지원하지 않는 레이아웃 이름을 임의로 만들지 않는다. HTML/CSS를 직접 수정할 경우 .slide 및 ID를 유지하고 재렌더링한다.
