# visual-curation

기관 공개 홍보 허가 사진 우선. 출처·사용권·아동 초상·외부 AI 전송 권한 확인. 스톡/생성 소재는 실제 시설이나 원아가 아님을 표시. 생성 도구가 있으면 글자 없는 자연스러운 다큐멘터리 사진을 생성한다. hero-left-copy는 왼쪽 밝은 여백, 오른쪽 아래 피사체. 반대 구도는 hero-right-copy. 과한 보케, 피부 보정, 스톡 미소 피하기. 사진 없으면 quiet-cover. sources.md에 출처와 사용 권한을 기록한다.

## v0.4 사진 품질 및 다양성
캐러셀 사진은 서로 다른 장면이어야 한다. wide/medium/close-up, 정면/측면/상부, 활동 전경/손 디테일/완성 작품을 분산한다. 동일 이미지의 크롭만 바꿔 반복하지 않는다. 생성 프롬프트에는 candid documentary photography, natural window light, unposed moment, believable classroom details, realistic hands and proportions를 구체화한다. 과도한 보케, 피부 보정, 광고 모델 같은 포즈를 피한다. 실제 원아 사진은 보호자 동의와 외부 AI 전송 권한이 확인된 경우에만 사용한다.
