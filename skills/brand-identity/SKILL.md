# brand-identity

기관명, 운영 목적, 학부모 대상, 지역, 강점, 문체를 추출한다. 색상은 primary/background/accent의 세 가지 HEX로 정의한다. 목표가 모집이면 확인된 출생연도와 입소 시기를 사용하고, 일상 소개면 실제 활동만 사용한다. 제공되지 않은 시설·인원·수상·연락처는 창작하지 않는다. 사진 미제공 시 그래픽 중심 스타일을 선택한다.

## 기관 프로필 연계
`institution-onboarding`에서 확인한 기관 프로필을 우선 읽는다. 최초 설정 질문을 반복하지 않는다. 주요 연령대, 교육 철학, 강점, 운영 목적, 원하는 말투를 현재 콘텐츠에 반영한다. 기관명은 원장님 입력 그대로 사용한다. 프로필이 없어도 현재 요청에 충분한 정보가 있으면 진행한다. 확인되지 않은 정보는 보완 질문 또는 초안으로 처리한다.
