# export

README 설치 절차 후 `python scripts/render.py INPUT.json --out output/새폴더` 실행. 실패하면 원인을 수정하고 새 폴더에서 재실행한다. 출력된 preview.html, PNG, captions.md, review-report.json 및 editable 폴더를 전달한다. HTML 직접 수정 후 `python scripts/render.py --rerender --out output/기존폴더`를 실행한다. 사진과 폰트 권한 및 사실 검토는 사람이 수행한다.
