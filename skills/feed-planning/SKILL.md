# feed-planning

단일 게시물 1개, 전체 피드 기본 9개(최대 9개). 최신순 배열, 실제 게시 순서는 역순. 사진형 1장, 카드뉴스 3~6장. 목표에 따라 혼합한다. 동일 표지 구도 3회 연속 금지. 대표 게시물부터 검토한다.

## Bold Photo Editorial 피드 계획
기본 스타일에서는 각 슬라이드가 하나의 강한 사진과 하나의 핵심 헤드라인을 갖는다. 사진의 장면은 달라야 하지만 기관명 위치, 하단 그라데이션, 도입 문구/헤드라인/보조 문구의 위계는 일관되게 유지한다. 전체 프로필 3열 그리드에서 같은 사진이나 같은 피사체 크롭이 반복되지 않도록 장면과 색감의 리듬을 계획한다.

4장 캐러셀의 기본 흐름은 표지 → 활동 과정 → 활동의 의미 → 마무리다. 각 슬라이드는 서로 다른 사진을 사용한다. 제목은 짧고 강하게, 본문은 부모가 알아야 할 맥락을 보완하도록 한다. 정보량이 많아 큰 헤드라인 위주의 디자인과 충돌하면 editorial-hybrid 또는 minimal-information 스타일을 선택한다.

## Editorial Hybrid 대안
사진이 전달할 정보와 텍스트가 전달할 정보를 구분한다. 사진은 활동 장면·분위기·과정을 보여주고, 텍스트는 맥락·관찰·학부모에게 필요한 설명을 보완한다. 4장 캐러셀은 표지 → 활동 디테일 → 활동의 의미 → 마무리 흐름을 기본 참고안으로 사용한다.
