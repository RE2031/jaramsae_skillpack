# feed-planning

단일 게시물 1개, 전체 피드 기본 9개(최대 9개). 최신순 배열, 실제 게시 순서는 역순. 사진형 1장, 카드뉴스 3~6장. 목표에 따라 혼합한다. 동일 표지 구도 3회 연속 금지. 대표 게시물부터 검토한다.

## Editorial Hybrid 계획
게시물마다 사진이 전달할 정보와 텍스트가 전달할 정보를 구분한다. 사진은 활동 장면·분위기·과정을 보여주고, 텍스트는 맥락·관찰·학부모에게 필요한 설명을 보완한다. 사진-only 게시물과 정보-only 게시물이 한 피드에 섞일 수 있지만, 전체 피드에서 사진과 정보의 균형을 유지한다. 4장 캐러셀은 표지 → 활동 디테일 → 활동의 의미 → 마무리 흐름을 기본 참고안으로 사용하되 콘텐츠에 맞게 조정한다.
