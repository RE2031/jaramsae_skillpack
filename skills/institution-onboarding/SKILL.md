# institution-onboarding

## 실행 시점
- 최초 설정 요청이거나 해당 기관의 확인된 프로필이 없는 경우 `prompts/onboarding.md`를 읽는다.
- 사용자가 이미 알려준 답변은 다시 묻지 않는다. 최초 설정 시 아직 답하지 않은 항목만 한 번에 간단히 묻는다.
- 사용자가 즉시 게시물 또는 표지 제작을 요청하면 필요한 기관명과 활동 정보만 확인하고, 나머지 선택 정보가 없다는 이유로 작업을 막지 않는다. 초기 설정 질문지는 별도로 제공할 수 있다.
- 기존 프로필이 있다면 정확한 기관인지 먼저 확인하고 재사용한다. 다른 기관의 프로필을 섞지 않는다.

## 수집 및 정리
원장에게 어린이집 이름, 주요 연령대, 교육 철학, 강점, 인스타그램 운영 목적(복수 선택), 원하는 분위기와 말투를 묻는다. 좋아하는 피드나 브랜드 정보는 선택 사항이다. 답변은 `schemas/brand-profile.schema.json`에 맞춰 정리한다. `examples/brand-profile.json`은 가상 예시이며 실제 기관에 자동 적용하지 않는다.

기관명은 사용자가 알려준 표기 그대로 보존한다. 미응답 선택 정보는 null 또는 빈 배열로 표시하고 임의로 채우지 않는다. 사용자가 제공한 사실과 AI가 제안한 스타일을 구분한다. 입력한 내용을 간단히 요약하고 원장님에게 수정 기회를 제공한다.

## 저장 및 재사용
- 앱의 기관별 저장소 또는 사용자가 지정한 비공개 작업 폴더에 기관 프로필을 저장할 수 있으면 JSON으로 저장한다. 로컬 개발 시 `profiles/<institution-id>/brand-profile.json`을 사용할 수 있다. 실제 고객 정보는 공개 Git 저장소에 커밋하지 않는다. 기관 ID는 저장 시스템이 부여한 안전한 식별자를 사용한다.
- 저장소와 파일 접근 권한이 없는 에이전트는 JSON을 제공하고 저장되지 않았다고 명시한다. 새 세션에서 자동 기억한다고 약속하지 않는다.
- 다음 제작 시 명시적으로 선택된 기관의 프로필을 불러온다. 현재 요청에서 원장님이 수정한 정보를 우선 적용하되 영구 변경 여부는 구분한다.
- 실제 아동 이름, 보호자 정보, 사진 등은 이 프로필에 수집하지 않는다. 사진 사용 권한은 사진별로 확인한다.

## 콘텐츠 제작에 연결
- institution → feed.json의 institution(표지 상단 중앙에 그대로 표시)
- age_range → 대상 연령 및 독자에게 맞는 표현
- education_philosophy, strengths → 주제 방향과 기관의 확인된 특징
- instagram_goals → 게시물 목적과 기획
- preferred_tone → 한국어 카피 및 아트디렉션

디자인 지정이 없으면 v0.7 Signature Cover 기본 규칙을 적용한다. 프로필은 표지 디자인을 임의로 변경할 권한이 아니다. 기관이 별도 스타일을 명시적으로 요청하면 해당 스타일을 검토한다. 색상 등 feed.json의 필수 디자인 값은 style-direction에서 정하고 기관 사실과 구분한다.

신규 원아 모집이 목적일 경우 실제 입소 가능 연령/출생연도, 인원, 모집 시기 및 문의 방법은 해당 게시물 제작 시 따로 확인한다. 목표를 모집 확정 사실로 해석하지 않는다.

설정 완료 후 원장님에게 "앞으로는 활동 내용이나 사용 승인 사진만 전달해 주세요."라고 안내한다(저장 여부와 재사용 가능 범위를 정확히 설명). 콘텐츠 생성 요청이 없으면 게시물을 임의로 생성하지 않는다.
