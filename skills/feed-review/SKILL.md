# feed-review

기관명, 연락처, 모집 대상·시기, 정책 등 사실은 기관 확인 또는 공식 자료를 요구한다. 아동 식별 가능 사진, 이름표, 위치 정보 등 공개 동의 범위를 검토한다. 동의가 불명확하면 제외한다. 외부 AI 전송 권한도 별도로 확인한다.

Editorial Hybrid 관점에서 다음을 추가 확인한다.
- 학부모가 활동 내용을 쉽게 이해할 수 있는가?
- 사진과 텍스트가 서로 보완하는가?
- 교육적 의미가 실제 활동/관찰에 근거하는가?
- 정보가 지나치게 많거나 추상적인 표현만 있지 않은가?
- 기관이 전문적이고 신뢰감 있게 관리된다는 인상을 주는가?

모든 슬라이드를 열어 넘침, 대비, 모바일 가독성, 오탈자, 일관성을 확인한다. 자동 검사 통과만으로 게시 승인 처리하지 않는다.
