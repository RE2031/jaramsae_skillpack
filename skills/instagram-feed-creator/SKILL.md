# instagram-feed-creator

1. brand-identity와 style-direction으로 기관 목적, 독자, 브랜드 및 확인된 사실을 정리한다.
2. reference-analysis와 `references/styles/bold-photo-editorial.json`, `references/design-rules.md`를 읽는다. 기관 고유 브랜드 요청이 없다면 기본 스타일은 `bold-photo-editorial`이다. 정보가 많은 안내/체크리스트를 요청하면 `editorial-hybrid` 또는 `minimal-information`을 선택할 수 있다.
3. visual-curation으로 각 슬라이드에 사용할 서로 다른 사진을 준비한다. 기본 스타일에서는 모든 슬라이드에 승인된 이미지가 필요하다. 실제 기관 사진은 공개 및 외부 AI 전송 권한을 확인한다. 생성 사진은 글자·로고·워터마크 없이 만들고, 모든 문구와 기관명은 HTML/CSS 텍스트로 렌더링한다. 생성 사진을 실제 기관이나 원아 사진으로 오인시키지 않는다.
4. feed-planning, editorial-copywriting, post-composition을 적용한다. 단일 요청에는 1개, 전체 피드에는 기본 9개. 사용자가 지정한 개수와 슬라이드 수를 우선한다.
5. 기본 디자인은 사진이 캔버스 전체를 채우는 full-bleed 구성이다. 상단 중앙에 작은 기관명, 하단에는 어두운 그라데이션, 작은 도입 문구와 정확히 두 줄의 굵은 흰색 제목을 배치한다. 첫 장에는 보조 설명을 넣지 않는다. 화면을 여백이나 장식 도형으로 채우지 않는다.
6. 한 슬라이드에는 하나의 핵심 메시지만 둔다. 첫 장 제목은 정확히 2줄, body는 빈 문자열이다. 이후 장의 제목과 본문은 목적에 맞게 구성한다. 사진은 활동의 맥락을 보여주고 텍스트는 부모가 이해할 정보를 보완한다.
7. anti-ai-aesthetic를 적용해 JSON 작성. `schemas/feed.schema.json`을 따른다. 사진은 JSON 기준 상대 경로, `image_approved`는 사용 권한을 확인한 경우만 true. 생성/스톡 사진은 `image_kind`와 `image_credit`를 기록한다.
8. pipeline-execution을 반드시 읽고 실행한다. AI 콘텐츠 JSON과 이미지 파일을 준비한 뒤 `python scripts/pipeline.py INPUT.json --out output/고유한-작업명`을 실제 터미널에서 실행한다.
9. 파이프라인 성공 및 quality_check 통과를 확인한다. visual-critique와 feed-review로 실제 PNG를 열어 기술 품질, 디자인, 정보 전달, 사실/권한을 각각 검토하고 발견된 문제를 수정한다.
10. PNG 개수와 1080×1350 크기, HTML/CSS 존재, 독립형 preview.html을 확인한 후 결과물 경로와 사진 출처, 검수 상태를 전달한다. 자동 게시 금지.

## 기본 스타일: Bold Photo Editorial
사용자가 제공한 피드 레퍼런스에서 관찰한 디자인 원리인 풀블리드 사진, 강한 하단 명암, 작은 도입 문구, 대형 흰색 헤드라인, 상단 브랜드 위치, 작은 출처 표기를 기관 콘텐츠에 맞게 재해석한다. 특정 계정의 로고, 사진, 문구, 고유 템플릿은 복제하지 않는다.

- 기본 시각 비중은 사진 약 75%, 텍스트 약 25%다.
- 사진은 1080×1350 캔버스를 끝까지 채우며 외곽 카드 여백을 두지 않는다.
- 사진의 주요 피사체는 가급적 상단/중앙에 배치하고 하단 40~50%에는 제목을 읽을 수 있는 어두운 그라데이션을 둔다.
- 상단 중앙에는 원장님이 입력한 기관명을 그대로 배치한다.
- 첫 장 하단에는 작은 도입 문구 1줄 → 굵고 큰 제목 2줄 → 우측 하단 출처만 둔다.
- 기관 브랜드 컬러는 작은 포인트로만 사용하고 흰색 제목과 충분한 명암 대비를 확보한다.
- 모든 텍스트는 HTML/CSS 레이어로 출력해 수정 가능하게 한다. 이미지 생성 단계에서 글자나 로고를 만들지 않는다.
- 한 게시물의 슬라이드들은 같은 그래픽 문법을 유지하되 사진 장면과 촬영 거리는 다양하게 한다.

## 기본 4장 캐러셀 흐름
사용자가 별도 구성을 지정하지 않았을 때 참고하며, 실제 활동과 사진에 맞춰 조정한다.
1. Cover: 활동이 한눈에 보이는 대표 장면 + 짧은 도입 문구 + 강한 제목.
2. Activity: 아이의 손, 재료, 상호작용 등 구체적인 과정 사진 + 짧은 설명.
3. Meaning: 실제 관찰에 근거한 놀이의 의미 또는 부모가 알아야 할 정보 + 관련 사진.
4. Closing: 완성 작품이나 활동을 마무리하는 장면 + 짧은 정리 문구.

## 다른 스타일 선택
- `editorial-hybrid`: 사진과 정보의 균형이 더 중요하고, 설명이 필요한 콘텐츠.
- `minimal-information`: 모집 일정, 준비물, 운영 안내 등 정확한 정보가 중심인 콘텐츠.
- 기관이 별도 브랜드 가이드를 제공하면 해당 가이드를 우선한다.

## v0.7 Signature Cover — 사용자 승인 표지
기본 bold-photo-editorial의 각 게시물 첫 장(단일 게시물 포함)에 필수 적용한다. 기존 다른 스타일과 2장 이후의 정보형 레이아웃은 유지한다.
- 1080×1350, 4:5. 사진을 화면 끝까지 채운다. 흐린 좌우 확장 배경, contain, 사진 축소 금지.
- 상단 중앙에는 원장님이 입력한 institution을 그대로 표시한다. 임의 기관명·타사 로고 금지.
- 아이의 얼굴·손·활동 소재(블록 등)가 크게 보이도록 원본을 확대하고 초점을 조정한다. 배경 가구보다 활동이 중심이다. 필요한 경우 원본 사진을 다시 고르거나 크롭한다. 얼굴이나 손·소재를 가리지 않도록 검수한다.
- 하단에는 활동을 나타내는 작은 얇은 도입 문구 1줄(eyebrow, 예: 오늘의 놀이 기록, 오늘의 교육 활동)과 굵은 흰색 제목 정확히 2줄만 배치한다. title에 명시적 줄바꿈 하나를 넣는다. 넘치면 문구를 다시 쓰고 글씨를 작게 줄이지 않는다.
- 표지 body는 빈 문자열, details는 비워 둔다. 설명은 다음 장 또는 caption에 넣는다. 제목 아래 설명·슬라이드 번호·분류 반복 금지.
- 우측 하단은 출처 | Pexels처럼 실제 출처만 작게 표시한다. stock의 image_source에는 실제 플랫폼명을, image_credit에는 상세 출처/저작자 정보를 기록한다. 생성 사진은 출처 | AI 생성으로 명시한다. 기관 제공 사진은 실제 출처에 맞게 표시한다.
- 스톡 사진을 실제 원아나 활동 기록처럼 오인시키지 않도록 caption에 대체 사진임을 명시하고 사용 권한을 검증한다. Pinterest는 원본 권리 확인 없이 사용하지 않는다. 생성/스톡 표시 및 게시 승인 상태는 표지의 추가 본문이 아니라 캡션·검수 보고서에 기록한다.
- 하단 그라데이션을 제한해 얼굴과 활동을 밝고 선명하게 유지한다. PNG를 실제로 열어 아이와 소재가 충분히 큰지 확인한다.
- image_zoom(1~3), image_focus_x/y(0~100)를 필요에 맞게 조정할 수 있다. 기본 확대 1.15, 중심 초점 50/50은 출발값이며 사진마다 수정한다.
