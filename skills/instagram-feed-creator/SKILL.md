# 인스타그램 카드뉴스 제작

[빠른 제작 규칙](../../references/quick-spec.md)에 따라 표시 이름, 게시물 주제, 사진, 원고를 한 번 받는다. 맥락 소개, 핵심 카드, 결말이나 후속 질문을 중심으로 본문 세 장을 시작한다.

표지는 기존 Signature 렌더러를 사용한다. 내용에 맞는 본문 스타일을 선택하고 비교를 요청하면 같은 자료로 네 스타일을 만든다. 아기자기 편집형은 사진 속 물건과 말풍선이 대화를 이루게 쓴다. 사진 오버레이형은 로고와 핵심 카피의 위치를 고정한다. 영상 매거진형은 무음으로도 읽히는 문구를 붙이고 앞뒤 사진으로 내용을 연결한다. 인터뷰 지면형은 원문에서 정확한 직접 인용을 가져와 지면의 중심에 둔다.

스튜디오 편집기의 문구 수정 사항을 실제 출력에 반영한다. 정지 PNG와 자막 합성 MP4를 장 순서대로 확인한다. CLI 제작은 빠른 제작 규칙의 명령을 실행하고 결과와 검수 상태를 전달한다.
