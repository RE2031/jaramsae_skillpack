# 인스타그램 카드뉴스 제작

기본 제작 계약은 [빠른 제작 규칙](../../references/quick-spec.md)이다. 주제, 표시 이름, 사진과 검증된 원고를 한 번만 받는다. 기존 기관 프로필은 재사용하고 일반 게시물에는 화면에서 입력한 표시 이름을 사용한다.

승인된 Signature 표지를 공유하고 요청한 본문 스타일만 적용한다. 본문 스타일은 원고와 미디어에 맞춰 고른다. 비교를 요청하면 동일한 자료로 네 스타일을 만든다. 인터뷰 인용은 제공된 원문에서 확인하고, 영상의 핵심 문구는 무음으로 읽힐 만큼 구체적으로 쓴다.

스튜디오 결과를 기존 카드 편집기에 연결한다. 편집한 문구와 사진을 최종 파일에 반영하고 정지 PNG와 자막 합성 MP4를 장 순서대로 확인한다. CLI 요청은 빠른 제작 규칙의 명령을 실제 실행하고 결과와 검수 상태를 전달한다.
