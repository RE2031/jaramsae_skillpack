# cardnews-design

references/design-rules.md를 읽는다. slides의 layout은 photo, editorial, magazine, info, quote, checklist 중 선택한다. 이미지가 없으면 photo 대신 info 또는 editorial을 사용한다. 사진 사용 권한을 확인한 경우에만 image와 image_approved=true를 설정한다. 실제 시설처럼 보이는 합성 이미지는 금지한다. 제목과 본문은 이미지에 굽지 말고 HTML 텍스트로 유지한다.
