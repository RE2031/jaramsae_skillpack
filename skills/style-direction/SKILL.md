# style-direction

기관 목적·독자·실제 강점·희망 분위기를 정리한다. 브랜드 무드 한 문장, 키워드 5개, 팔레트, 사진 조명과 구도, 제목 서체와 금지 요소를 정의한다. 기관이 이미 보유한 브랜드 가이드가 있으면 이를 우선한다.

## 기본 Editorial Hybrid
별도 요청이 없으면 editorial-hybrid를 기본값으로 사용한다.
- 무드: warm, professional, friendly, informative, editorial.
- 사진: 실제 활동 맥락이 드러나는 자연광 다큐멘터리 스타일.
- 색상: 크림/오프화이트 배경, 차콜 텍스트, 올리브 포인트를 출발점으로 하되 기관 브랜드 색상 우선.
- 타이포그래피: 큰 한국어 제목, 읽기 쉬운 본문, 제한된 서체 조합.
- 구성: 사진과 정보의 균형, 충분한 여백, 명확한 시각적 위계.
- 피할 것: 사진만 이어지는 구성, 긴 텍스트 덩어리, 과도한 파스텔/장식, 의미 없는 아이콘, 반복 템플릿.
