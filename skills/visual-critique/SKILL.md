# visual-critique

PNG를 열고 모바일 축소 크기에서도 확인한다. 사진 크롭·피사체 가림·제목 대비·줄바꿈·여백·시각 중심·피드 다양성·예시 이미지 표시를 검토한다. 문제가 있으면 CSS/카피를 수정하고 재렌더한다. 자동 검사와 시각 검수 결과를 구분한다. 도구가 없으면 사람 검토 필요로 표시한다. 유명 브랜드와 같은 품질을 보장하지 않는다.

## v0.4 시각 평가
각 장뿐 아니라 캐러셀 전체를 연속해서 확인한다. 반복 레이아웃/사진, 어색한 손·얼굴, 생성 이미지 질감, 사진과 글자 충돌, 타이포그래피 리듬, 색감 연속성을 검토한다. 문제가 있으면 layout/image_position/카피를 수정하고 재렌더한다. preview.html도 별도로 열어 이미지가 보이는지 확인한다.
