# visual-critique

PNG를 열고 모바일 축소 크기에서도 확인한다. 사진 크롭·피사체 가림·제목 대비·줄바꿈·여백·시각 중심·피드 다양성·예시 이미지 표시를 검토한다. 문제가 있으면 CSS/카피를 수정하고 재렌더한다. 자동 검사와 시각 검수 결과를 구분한다. 도구가 없으면 사람 검토 필요로 표시한다. 특정 브랜드와 같은 품질을 보장하지 않는다.

## Bold Photo Editorial 평가
각 항목을 1~5점으로 평가하고 근거를 기록한다.
- 사진 임팩트: 첫눈에 활동 주제와 장면이 이해되는가?
- 타이포그래피: 제목이 크고 선명하며 2~3줄에서 잘 읽히는가?
- 대비: 하단 그라데이션이 제목을 받치고 사진을 과도하게 가리지 않는가?
- 정보 전달: 도입 문구/제목/보조 문구가 서로 다른 역할을 하는가?
- 브랜드 일관성: 상단 기관명과 그래픽 문법이 피드 전체에서 일관적인가?
- 사진 진정성: 손·얼굴·재료·교실 환경이 자연스럽고 활동과 관련 있는가?

모든 PNG를 실제로 열고 모바일 크기로 축소해 확인한다. 주요 얼굴/활동이 제목에 가려지지 않는지, 글자가 하단에서 잘리지 않는지, 사진별 장면이 중복되지 않는지 확인한다. 자동 검수 통과와 디자인 승인은 구분한다. 정보가 부족하면 editorial-hybrid를 대안으로 제안한다.

## v0.7 첫 장 필수 우선 규칙
`references/signature-cover.md`를 따른다. 아래/위의 일반 캐러셀 규칙보다 우선하며 이후 슬라이드 및 다른 프리셋에는 기존 지침을 유지한다.
첫 장에서 제목 정확히 두 줄, 도입 문구 한 줄, 기관명 일치, 보조 설명 부재, 출처 위치, 사진 풀블리드 및 얼굴·손·활동 소재 확대, 그라데이션이 활동을 가리지 않는지 확인한다. 자동 검사는 구조와 넘침만 확인하므로 사진 구도는 실제 PNG 시각 검수 필수.

## TIO 우선 매거진 시안 — 최신 우선 지침
`references/magazine-editions.md`를 먼저 읽는다. TIO(@tio_korea)는 표지 최우선 레퍼런스이며 기존 승인 Signature Cover는 A에 그대로 보존한다. MMM, Eyesmag, 생매거진, Our Expresso는 시안별 보조 레퍼런스다. B/C/D도 풀블리드, 상단 중앙 기관명, 하단 얇은 도입 문구, 정확히 두 줄 굵은 흰색 제목, 우측 하단 출처, 표지 본문 없음이라는 TIO 기반 구조를 유지하면서 타이포/명암/여백을 변주한다. 네 시안에서 사진·활동 사실·카피·브랜드는 동일하게 유지하고 실제 CSS 배치·서체·사진 영역을 다르게 한다. 본문은 아직 사용자 최종 승인 전인 후보 디자인이며 기존 A를 유지한다. 네 시안은 각 4장 한 줄, 총 16장 편집기로 제공한다. 단일 표지 요청에는 A를 기본으로 한다. 원본 권리 확인 및 실제 파이프라인 검수는 기존 규칙을 유지한다.
