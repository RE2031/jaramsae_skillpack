# visual-critique

PNG를 열고 모바일 축소 크기에서도 확인한다. 사진 크롭·피사체 가림·제목 대비·줄바꿈·여백·시각 중심·피드 다양성·예시 이미지 표시를 검토한다. 문제가 있으면 CSS/카피를 수정하고 재렌더한다. 자동 검사와 시각 검수 결과를 구분한다. 도구가 없으면 사람 검토 필요로 표시한다. 유명 브랜드와 같은 품질을 보장하지 않는다.

## Editorial Hybrid 평가
각 항목을 1~5점으로 평가하고 근거를 기록한다.
- 디자인 완성도: 큰 제목, 타이포그래피, 여백, 정렬, 색상 조화.
- 사진 품질: 자연스러움, 장면 다양성, 구도, 활동과의 관련성.
- 문구 품질: 자연스러운 한국어, 짧고 명확한 표현, 과장 여부.
- 정보 전달력: 학부모가 활동 내용과 의미를 이해할 수 있는가.
- 기관 브랜드 인상: 전문성, 신뢰감, 일관성이 전달되는가.

캐러셀 전체를 연속해서 확인한다. 사진-only 또는 텍스트-only 슬라이드가 연속되는지, 반복 레이아웃/사진, 어색한 손·얼굴, 사진과 글자 충돌, 타이포그래피 리듬, 색감 연속성을 검토한다. 자동 검수 통과와 디자인 승인은 구분한다. 사용자가 좋다고 평가한 자연스러운 한국어 카피 톤은 유지하면서 디자인/사진 문제를 우선 수정한다.
