# 승인된 방향: 햇살숲 어린이집 예시
가상 기관의 4:5 모집 포스터를 기준으로 한다. 원본 예시는 생성 이미지이며 실제 시설/원아가 아니다. 동일 이미지를 고정 배경으로 복제하지 않는다.
- 자연광 전체 배경 사진, 왼쪽 밝은 벽과 오른쪽 아래 피사체, 원목과 크림/올리브.
- 상단 작은 기관명, 올리브 모집 라벨, 큰 한국어 명조 제목 2줄, 짧은 구분선과 보조 문구, 모집 정보 1~2줄.
- 사진이 하단을 지배하고 글자는 상단의 조용한 영역에 둔다.
- 스톡/생성 소재는 실제 기관이 아님을 표시한다. 기관별 브랜드에 맞게 변주한다.
