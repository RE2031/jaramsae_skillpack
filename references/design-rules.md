# 디자인 규칙
1080×1350px, 기본 안전 여백 84px, 제목 76px 내외, 본문 43px 내외. 모바일에서 읽을 수 있도록 본문을 짧게 쓴다. 표지에는 한 가지 메시지, 기관 이름, 분류 라벨을 배치한다. 피드 미리보기는 세 열, 최신 게시물 우선. 3:4 중앙 크롭에서도 주요 내용이 보이도록 좌우 여백을 유지한다. 사진 중심형은 실제 사진 위 가독성 있는 제목, 감성형은 여백과 세리프 선택, 매거진형은 짙은 헤드라인 영역, 정보형은 큰 제목과 명확한 번호를 활용한다. 색상 대비를 직접 확인한다. 사진 없는 경우 추상 도형을 사용하고 실제 기관 사진으로 오인시키지 않는다.
