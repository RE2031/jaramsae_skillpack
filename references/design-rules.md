# 디자인 규칙

기본 캔버스는 1080×1350px(4:5), 기본 안전 여백 84px, 제목 76px 내외, 본문 43px 내외다. 모바일에서 읽을 수 있도록 본문을 짧게 쓴다. 표지에는 한 가지 메시지, 기관 이름, 분류 라벨을 배치한다. 피드 미리보기는 세 열, 최신 게시물 우선. 3:4 중앙 크롭에서도 주요 내용이 보이도록 좌우 여백을 유지한다. 색상 대비를 직접 확인한다. 의미 없는 도형은 금지한다.

## 기본 스타일: editorial-hybrid
사진과 텍스트의 시각적 비중을 균형 있게 사용하는 기관형 에디토리얼 디자인이다. 50:50은 시작 가이드이지 고정 픽셀 비율이 아니다. 사진은 실제 활동의 분위기와 과정을 보여주고, 텍스트는 학부모가 활동의 맥락과 의미를 이해하도록 돕는다. 큰 한국어 제목, 짧은 설명, 충분한 여백, 명확한 위계를 사용한다.

- 사진-only 슬라이드와 텍스트-only 슬라이드가 연속되지 않도록 한다.
- 표지는 활동 대표 사진과 큰 제목/한 줄 설명을 사용한다.
- 활동 디테일은 손·재료·과정의 클로즈업과 짧은 설명을 조합한다.
- 의미 전달 슬라이드는 타이포그래피 중심이 될 수 있지만 긴 본문은 피한다.
- 마무리는 결과물이나 자연스러운 활동 장면과 짧은 문구를 사용한다.
- 실제 기관 브랜드 가이드가 있으면 기본 팔레트보다 우선한다.

## 레이아웃별 참고
사진 중심형은 실제 사진 위 가독성 있는 제목, 감성형은 여백과 세리프 선택, 매거진형은 짙은 헤드라인 영역, 정보형은 큰 제목과 명확한 번호를 활용한다. 사진 없는 경우 quiet-cover 또는 minimal-announcement를 사용한다.
