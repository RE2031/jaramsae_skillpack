# Magazine Body — 승인된 기사형 본문
## 입력
어린이집/반 이름(반은 선택), 이번 호 활동, 교사 기록(행동·발언·교사 지원), 사용 승인 현장 사진과 사진별 설명. 이미 받은 정보는 반복 질문하지 않는다.
## 기사 흐름
2장: 놀이의 시작 — 관심을 보인 순간과 시작 계기.
3장: 아이들이 해본 일 — 손·도구·상호작용, 시도와 변화.
4장: 이어진 놀이 — 기록에 확인된 결과나 변화. 교사의 지원은 기록에 있을 때만 연결한다.
각 장에 서로 다른 사진, 새 정보를 담은 소제목, 따뜻하고 담백한 존댓말 2~3문장. 사진으로 모르는 맥락은 교사 기록에서만 가져온다. 실제 기록된 발언만 직접 인용한다. 추측, 과장, 발달 효과 단정, 참고 사진을 실제 기관 활동으로 묘사하는 일 금지. 빠진 장면은 안내하고 자료가 충분한 만큼만 제작한다.
## 디자인
1080×1350, 4:5. 상단 약 55~65% 큰 사진, 하단 밝은 단색 영역에 작은 라벨·소제목·본문·페이지 번호·작은 실제 출처. 기관명과 로고 반복 없음. 사진과 글은 겹치지 않는다. A 아이보리/따뜻한 명조, B 흰색/고딕, C 따뜻한 종이색/명조, D 옅은 기관색/고딕. 모바일 가독성과 사진 크롭을 확인한다. 모든 문구는 편집 가능한 HTML 텍스트로 렌더링한다. 기본 4시안은 동일한 사진·사실·문구를 사용한다. 표지 제외 요청에는 2~4장만 제공한다.
